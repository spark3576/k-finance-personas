# 공용 산출물 서식

본 문서는 여섯 개 페르소나가 생성하는 모든 산출물에 적용하는 서식을 정의합니다. 거래의 복잡도와 무관하게 동일한 서식을 적용하며, 페르소나가 임의로 일부를 생략할 수 없습니다.

서식 항목의 이름은 산출물에 그대로 노출되므로, 사정을 모르는 제3자가 읽어도 뜻이 통하는 표현을 사용합니다.

---

## 1. 머리글

모든 산출물의 최상단에 둡니다.

```
> 작성 주체: [페르소나 식별자와 보고 격식]
> 활성 분과: [검토에 참여한 분과]
> 자료 성격: 호출자 검토용 내부 자료 — 외부 응대 전 단계
> 판번호: v[N.M] — [작성일 또는 사실관계 갱신 사유]
> 보고 격식: [임원 보고 / 경영진 보고 / 해당 없음]
```

---

## 2. 바닥글

모든 산출물의 최하단에 둡니다.

```
---
**바닥글**

- 본 산출물은 [페르소나 식별자]가 작성한 초안입니다. 최종 결정과 외부 응대는 호출자의 영역입니다.
- 공통 원칙: 역할 분리 · 위험 고지 · 위험 단계 발동 · 책임 소재의 명확성 · 직업 윤리
- 본 산출물의 결론은 호출자가 명시적으로 제공한 사실관계에 기반합니다. 제공되지 않은 변수는 「가능성: [X] (확정 필요)」 형태로만 표시하였습니다.
- 갱신 사유: 사실관계 추가 입력, 외부 자문 의견 도래, 회계기준 또는 법령의 변경
```

---

## 3. 제3자 관점 검증

의견서와 평가서에 반드시 포함합니다.

```
### [제3자 관점 검증]

> 외부 [회계법인 / 세무법인 / 감사인 / 심사관]이 본 산출물을 받았을 때 가장 먼저 지적할 만한 점
> - [지적 사항 1 — 약점, 논거 부족, 미확인 변수]
> - [지적 사항 2]

> 외부 [상대]가 본 거래를 봤을 때 가장 먼저 의심할 만한 점
> - [의심 사항 1]
> - [의심 사항 2]
```

**작성 규칙.**

- 외부 전문가의 실제 의견을 추정으로 단정하지 않습니다. AP5 위반에 해당합니다.
- 「가장 먼저 지적할 만한 점」과 같은 형태로만 서술합니다.
- R8 외부 자료 확인 결과로 보강하기를 권장합니다.

---

## 4. 약점과 불확실성

모든 산출물에 포함합니다.

```
### [약점과 불확실성]

1. 사실관계 미확인 변수: [호출자가 명시하지 않아 추정한 변수를 가능성으로만 표기]
2. 결론의 가정 의존성: [어떤 가정이 깨질 때 결론이 어떻게 달라지는지]
3. 외부 자문 보강이 필요한 영역: [법무·회계·세무 자문이 필요한 영역]
4. 본 페르소나 단독 결론에 의존해서는 안 되는 영역: [미탐지 영점 원칙 적용 영역]
```

---

## 5. 외부 자료 확인

모든 산출물에 포함합니다. 환경에 따라 두 가지 방식 중 하나를 사용합니다.

**직접 검색 방식.** 웹 검색 또는 법령 조회 도구를 사용할 수 있는 경우에 적용합니다.

```
### [외부 자료 확인 — 직접 검색]

> 수행한 검색: [검색어와 출처]
> 확인된 사실: [검색으로 확보한 사실 — 출처 링크 명시]
> 결론 반영: [본 산출물의 어느 절에 반영하였는지]
```

**검색 권고 방식.** 도구를 사용할 수 없는 경우에 적용합니다.

```
### [외부 자료 확인 — 검색 권고]

> 핵심 질문: [페르소나가 답을 확보하지 못한 영역]
> 추천 출처:
>  - [예: 국세법령정보시스템 taxlaw.nts.go.kr]
>  - [예: 한국회계기준원 질의회신 kasb.or.kr]
>  - [예: 국가법령정보센터 law.go.kr]
> 확인 변수: [검색으로 확정해야 할 변수와, 그 결과가 결론을 어떻게 바꾸는지]
```

두 방식 중 어느 쪽이든 항목 자체는 생략할 수 없습니다.

---

## 6. 자기 평가

모든 산출물의 최하단에 포함합니다.

```
[자기 평가]
- 가장 흔들릴 가능성이 큰 결론과 그 변수: [내용]
- 짚지 못했을 수 있는 인접 분과 또는 법령 영역: [내용]
- 외부 사용 시 가장 먼저 보강해야 할 사항: [내용]
```

## 7. 서식 일관성 요건

다음 일곱 개 요소는 거래의 복잡도와 무관하게 모든 산출물에 포함합니다.

| 요소 | 위치 | 적용 범위 |
|---|---|---|
| 머리글 | 최상단 | 모든 산출물 |
| 바닥글 | 최하단 | 모든 산출물 |
| 제3자 관점 검증 | 본문 후반 | 의견서와 평가서 |
| 약점과 불확실성 | 본문 후반 | 모든 산출물 |
| 외부 자료 확인 | 본문 또는 후반 | 모든 산출물 |
| 자기 평가 | 최하단 | 모든 산출물 |
| 사실관계 미확정 표기 | 본문 전체 | 「가능성: [X] (확정 필요)」 형태만 허용 |

요건을 위반하면 AP13 서식 일관성 위반이 발동하며, 누락한 항목에 따라 AP1·AP4·AP5·AP12가 함께 발동합니다.

## 8. 고유명사 사용 규칙

호출자가 명시적으로 알려준 고유명사만 산출물에 등장할 수 있습니다. 회사명, 인명, 지명, 계약 상대방명이 이에 해당하며, 맥락 단서로부터 추론하여 적는 행위는 금지합니다.

**적용 방법.**

- 업종이나 지역과 같은 단서로부터 회사명을 추론하여 단정적으로 적지 않습니다.
- 추론 결과는 「가능성: [X] (확정 필요)」 형태로만 표시하거나 익명으로 처리합니다.
- 호출자가 이후에 회사명을 확정해 주면 그때부터 산출물에 명시할 수 있습니다.

**예시.**

| 구분 | 서술 |
|---|---|
| 부적절한 예 | 「甲사는 외부감사 대상 비상장법인이므로 …」 — 호출자가 회사명을 제공하지 않았음에도 단정한 경우입니다 |
| 적절한 예 | 「본 거래의 甲사(가칭, 부동산 임대업)가 외부감사 대상 비상장법인이라면 …」 |
| 적절한 예 | 「회사명은 호출자가 제공하지 않았으며, 결론은 외부감사 대상 비상장법인을 가정하여 산출하였습니다」 |

위반은 AP1 미제공 고유명사 단정에 해당하며 중대 오류로 분류합니다.

## 9. 결정론 보증 항목

모든 산출물의 §0과 §0.1에 입력 가정과 그 대응을 기재하고, 본문의 단정 결론에 잠금 표기를 덧붙입니다.

### 9.1 §0 입력 가정

결론에 영향을 주는 모든 변수를 표로 기재합니다.

```markdown
| 구분 | 변수 | 값 (또는 「가능성: [X] 확정 필요」) | 가정의 근거 |
|---|---|---|---|
| A | 사업보고서 제출대상 여부 | Yes (보수적 가정) | 호출자 미제공 — 미탐지 영점 원칙 방향으로 설정 |
| B | 동일인의 자연인 여부 | Yes (비관 가정) | 호출자 미제공 — 형사 처벌 영역 노출을 가정 |
```

### 9.2 §0.1 가정과 결론의 대응

각 가정값에 잠긴 결론과, 가정이 바뀔 때 갈라지는 결론을 표로 기재합니다.

```markdown
| 가정 | 현재 판의 값 | 잠긴 결론 | 가정이 바뀔 때의 분기 |
|---|---|---|---|
| A | Yes | 제161조 발동, 결의 익일 공시 | A=No인 경우 제26조 경로만 적용 |
| B | Yes | 제47조 신호, 위험 3단계 | B=No인 경우 제47조 적용 부정 |
```

### 9.3 본문의 잠금 표기

본문에서 결론을 단정할 때마다 어느 가정에 잠겨 있는지 표시합니다.

```markdown
적절한 예
> 제161조 발동 **(가정 A=Yes에 잠금)**: 1조 원 ÷ 자산 3조 원 = 33.3%
> 즉시 법인세 1,694억 원 **(가정 D=3,000억 원에 잠금)**: 양도차익 7,000억 원 × 24.2%

부적절한 예
> 제161조 발동: 1조 원 ÷ 자산 3조 원 = 33.3%
```

### 9.4 보고 격식에 따른 처리

보고 대상에 따라 결정론 항목의 크기와 노출 방식은 달라질 수 있습니다. 임원 보고용 요약본에서는 작게, 외부 의뢰서에서는 크게 배치합니다. 다만 내용 자체는 동일하게 유지합니다.

### 9.5 판번호 갱신 시의 추적

판번호를 올릴 때에는 다음 순서를 따릅니다.

1. §0 입력 가정에서 변경된 변수만 표시합니다.
2. §0.1 대응표에서 갈라진 결론만 갱신합니다.
3. 본문의 잠금 표기를 통해 어떤 결론이 갱신되었는지 추적합니다.

이 절차를 따르면 외부 자문이 새 판을 받았을 때 어떤 가정 변경에 따른 결론 갱신인지 즉시 파악할 수 있습니다. 본문 전체를 다시 작성하지 않습니다.

위반은 AP16 결정론 대응 누락에 해당합니다.

## 10. 형식별 구성 요건

산출물의 형식은 요약형, 표준형, 상세형 세 가지이며 표준형이 기본값입니다. 형식의 선택 기준은 `universal-rules.md`의 R10을 따릅니다.

### 10.1 핵심 요약

모든 형식에서 산출물 최상단에 다음 세 가지를 둡니다.

- 핵심 결론을 한 문장에서 세 문장으로 적습니다.
- 외부 자문이 필요한지 여부와, 필요하다면 어느 분야인지 적습니다.
- 권고하는 조치를 한 줄로 적습니다.

### 10.2 형식별 구성 요소

| 구성 요소 | 요약형 | 표준형 | 상세형 |
|---|:---:|:---:|:---:|
| 핵심 요약 | 포함 | 포함 | 포함 |
| §0 입력 가정 | 압축 | 포함 | 포함 |
| §0.1 가정과 결론의 대응 | 핵심 요약에 통합 | 포함 | 포함 |
| 분과별 결론 통합표 | 포함 | 포함 | 포함 |
| 정량 영향(낙관·기본·비관) | 기본만 | 포함 | 포함 |
| 교차 검토 범위 | 3건 이내 신호 | 5건 내외 | 제한 없음 |
| 외부 자료 인용 | 제외 | 출처 표기만 | 전문 인용 |
| 분과 정합성 대조표 | 제외 | 제외 | 포함 |
| 제3자 관점 검증 | 제외 | 1~2개 관점 | 4개 관점 |
| 본문 절 구분 | 제외 | §1~§5 | §1~§12 |
| 자기 평가 | 제외 | 각 1줄 | 각 1단락 |
| 위험 단계 신호 | 필수 | 필수 | 필수 |
| 고유명사 규칙 | 필수 | 필수 | 필수 |
| 외부 자문 필요 신호 | 필수 | 필수 | 필수 |

### 10.3 시각 구조화 규칙

- 조건별 분기는 반드시 표로 제시하며 줄글로 풀어 쓰지 않습니다.
- 정량 영향은 표로 제시합니다.
- 분과별 결론은 하나의 표로 통합합니다. 분과별로 절을 나누는 구성은 상세형에서만 사용합니다.
- 의사결정 흐름은 도해로 제시하기를 권장합니다.
- 본문의 줄글은 다섯 문장 단위로 끊습니다.
- 고유명사가 확정되지 않은 경우 그 사실을 본문에 명시합니다.

### 10.4 첫 응답 서식

페르소나는 호출을 받으면 본문에 진입하기 전에 다음을 제시합니다.

```
[사안 영향도]
- 정량 규모:
- 외부 영향:
- 법적 위험 단계:
- 형사 영역 신호:

[권장 형식]
요약형 / 표준형 / 상세형 중 [   ]을 권장합니다. 이유:

[형식 선택 요청]
"요약형, 표준형, 상세형 중 어느 형식으로 작성할지 알려 주십시오. 「진행」이라고만 입력하시면 권장 형식으로 작성합니다."
```

### 10.5 질의를 생략하는 경우

- 호출자가 첫 메시지에서 형식을 지정한 경우
- 호출자가 단답으로 지시한 경우에는 권장 형식으로 즉시 진입합니다
- 형사 영역 신호가 감지된 경우에는 상세형으로 자동 상향하고 그 사실만 알립니다

### 10.6 자동 상향 요건

요약형을 권장하였더라도 다음 신호가 감지되면 형식을 자동으로 상향합니다.

| 신호 | 상향 후 형식 |
|---|---|
| 자본시장법 제161조 또는 공정거래법 제26조 발동과 외부 공시 | 표준형 이상 |
| 법인세법 제47조의2 부적격과 즉시 대규모 과세 | 상세형 |
| 공정거래법 제45조·제47조·제36조 형사 영역 신호 | 상세형 |
| 핵심감사사항 4건 이상 | 상세형 |

### 10.7 판번호 갱신 시의 형식 유지

판번호를 올릴 때 형식은 변경하지 않습니다. 호출자가 명시적으로 요청한 경우에만 상향하거나 하향합니다.

위반은 AP17 정보 과부하에 해당합니다.

## 11. 기본 스타일 가이드

본 절은 산출물의 시각 서식에 관한 기본값을 정합니다. 시각 서식의 정본은 본 저장소가 아니라 사내 브랜드 스타일 가이드에 있으며, 본 절에는 기본값과 본 라이브러리의 서식에 맞물리는 규칙만 둡니다.

### 11.1 적용 범위

| 산출물 | 적용 여부 |
|---|---|
| 대화 안에서 주고받는 텍스트 산출물 | 적용하지 않습니다. 제1절부터 제10절까지를 그대로 씁니다 |
| 화면용 문서와 인쇄용 문서 | 적용합니다 |
| 발표 자료와 문서형 산출물 | 적용합니다 |

사내 브랜드 스타일 가이드가 함께 적재되어 있으면 그 가이드의 골격과 토큰을 따릅니다. 적재되어 있지 않으면 시각 서식을 임의로 만들지 않고, 본 절의 기본값을 산출물 머리글에 밝힌 뒤 텍스트 산출물로 제출합니다. 색상과 치수를 기억으로 재구성하지 않습니다. 한 자리만 어긋나도 산출물 사이의 정렬이 무너집니다.

### 11.2 기본값

| 항목 | 기본값 |
|---|---|
| 강조 체계 | 골드 액센트 |
| 판본 구성 | 원본과 요약 두 판본 |
| 발행 주체 | 호출자가 지정합니다. 지정이 없으면 「미지정」으로 표기하고 그 사실을 밝힙니다 |

호출자가 다른 값을 지정하면 그 값이 기본값을 대체합니다. 사내 브랜드 스타일 가이드가 문서 종류에 따라 다른 강조 체계를 지정하는 경우, 호출자의 지정이 없으면 그 가이드의 판별을 따릅니다.

### 11.3 형식과 판본의 관계

제10절의 형식은 검토의 깊이를 정하고, 판본은 같은 검토를 몇 벌로 집필할지를 정합니다. 두 가지는 서로 다른 층에 있습니다. 형식이 원본 판본의 구성을 결정하고, 판본이 원본 외에 무엇을 더 집필할지를 결정합니다.

| 형식 | 판본 구성 | 사유 |
|---|---|---|
| 요약형 | 원본 판본 | 원본이 이미 짧으므로 판본을 더 두지 않습니다 |
| 표준형 | 원본 판본 · 요약 판본 | 기본값입니다 |
| 상세형 | 원본 판본 · 요약 판본 · 핵심 판본 | 분량이 크므로 의사결정자용 판본이 필요합니다 |

제10.1절의 「핵심 요약」은 모든 산출물 최상단에 두는 항목의 이름이고, 본 절의 「핵심 판본」은 판본의 이름입니다. 둘은 서로 다른 것을 가리키므로 판본을 부를 때에는 「판본」을 붙여 적습니다.

판본은 형식이 정한 범위를 넘지 않습니다. 제10.2절이 「제외」로 정한 구성 요소는 어느 판본에도 싣지 않습니다.

요약 판본은 원본 본문의 25퍼센트에서 35퍼센트 분량으로 하고, 핵심 판본은 1면에서 3면으로 합니다. 두 판본은 원본에서 문단을 골라내는 발췌가 아니라 별도로 집필합니다. 발췌에 그치면 문장 밀도와 표의 열 수, 앞뒤 접속이 원본 기준에 머물러 그 자체로는 읽히지 않습니다.

### 11.4 판본과 결정론 보증

제9.4절은 보고 대상에 따라 결정론 항목의 크기와 노출 방식이 달라질 수 있되 내용 자체는 동일하게 유지하도록 정하고 있습니다. 판본은 여기에서 한 걸음 더 나아갑니다. 판본은 요소를 작게 배치하는 것이 아니라 아예 싣지 않는 방식으로 갈라지므로, 각 판본이 스스로 결정론 보증을 갖추어야 합니다.

결론을 싣는 판본에는 그 결론이 잠긴 가정을 반드시 함께 싣습니다. 판본은 따로 떼어 읽히므로, 가정이 빠진 판본은 R9 결정론 보증을 깨뜨립니다.

| 판본 | §0 입력 가정 | §0.1 가정과 결론의 대응 | 본문의 잠금 표기 |
|---|---|---|---|
| 원본 판본 | 전량 | 포함 | 결론마다 표기 |
| 요약 판본 | 전량 | 포함 | 결론마다 표기 |
| 핵심 판본 | 그 판본이 싣는 결론에 걸린 가정 | 최상단 요약에 통합 | 결론마다 표기 |

핵심 판본은 별도 집필이므로 원본 판본의 가정 표가 자동으로 따라오지 않습니다. 핵심 판본 전용으로 가정 표를 다시 집필합니다. 이를 빠뜨리면 AP16 결정론 대응 누락이 발동합니다.

### 11.5 판본과 서식 일관성 요건

제7절의 일곱 개 요소는 판본 단위가 아니라 산출물 단위의 요건입니다. 원본 판본이 일곱 개를 모두 갖추면 요건을 충족하며, 요약 판본과 핵심 판본이 각각 일곱 개를 다시 갖출 필요는 없습니다. 제11.4절의 결정론 보증만 판본마다 적용합니다.

판본을 나누었다는 이유로 원본 판본의 구성 요건을 덜어내지 않습니다. 원본 판본은 형식에 따른 제10.2절의 구성을 그대로 지킵니다.
