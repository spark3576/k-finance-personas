# 후속 작업

본 문서는 남은 작업을 수행 환경별로 정리합니다. 환경에 따라 가능한 일이 다르므로, 작업을 시작하기 전에 어느 환경에서 수행할지 먼저 확인합니다.

## 1. 환경별 가능 범위

| 작업 | Cowork | Claude Code | 사용자 직접 |
|---|:---:|:---:|:---:|
| 저장소 파일 읽기와 편집 | 가능 | 가능 | 가능 |
| 형상 관리 커밋과 태그 생성 | 가능 | 가능 | 가능 |
| 원격 저장소 반영 | 불가 | 가능 | 가능 |
| `~/.claude/skills/` 연결 관리 | 불가 | 가능 | 가능 |
| 연결되지 않은 폴더 접근 | 승인 필요 | 가능 | 가능 |
| 파일 삭제 | 승인 필요 | 가능 | 가능 |
| claude.ai 개인 스킬 등록 | 불가 | 불가 | 가능 |
| 대량 문서 개편 | 가능 | 권장 | 해당 없음 |

**원격 저장소 반영이 Cowork에서 불가한 이유.** Cowork의 셸은 사용자 컴퓨터와 분리된 가상 환경에서 실행되며, 연결된 폴더만 마운트합니다. 저장소 파일은 읽고 쓸 수 있으나 사용자 컴퓨터의 자격증명 저장소에는 접근하지 못하므로 인증이 필요한 원격 반영을 수행할 수 없습니다.

**연결 관리가 Cowork에서 불가한 이유.** `~/.claude/` 는 연결 대상 폴더 밖에 있으며, 도구가 접근을 차단하는 보호 영역입니다.

## 2. Claude Code에서 수행할 작업

### 2.1 원격 저장소 반영

```bash
cd ~/My_project/Claude_Project/k-finance-personas
git log --oneline -5
git status -sb
git push origin main --follow-tags
```

반영 후 태그가 원격에 존재하는지 확인합니다.

```bash
git ls-remote --tags origin
```

### 2.2 상세 매뉴얼 6종의 서술 기준 적용

`references/full-manual.md` 여섯 개가 아직 서술 기준에 맞추어 개편되지 않았습니다. 분량은 합계 약 1,500행입니다.

수행 절차는 다음과 같습니다.

```bash
cd ~/My_project/Claude_Project/k-finance-personas
python3 docs/tools/check_style.py                 # 현재 지적 사항 확인
# docs/04_문체기준.md를 먼저 읽고 기준을 확인합니다
# 파일별로 개편한 뒤 아래를 반복 실행합니다
python3 docs/tools/check_style.py <대상 파일>
```

개편 시 유지할 사항은 다음과 같습니다.

- 규칙 식별자 R1부터 R10까지와 오류 유형 식별자 AP1부터 AP17까지는 그대로 둡니다.
- 법령 조항 번호와 정량 임계치는 원문 그대로 옮깁니다.
- 개정 이력과 작업 경위가 본문에 있으면 `docs/06_개정이력.md`로 옮깁니다.

개편을 마치면 다음을 실행합니다.

```bash
python3 docs/tools/check_style.py                 # 전체 통과 확인
python3 docs/tools/sync_shared.py --check         # 사본 일치 확인
```

### 2.3 Claude Code 연결 확인

```bash
ls -l ~/.claude/skills/ | grep -E "orchestrator|s[1-5]-"
```

연결이 끊어졌다면 다시 만듭니다.

```bash
cd ~/My_project/Claude_Project/k-finance-personas
for p in orchestrator s1-accounting-reviewer s2-external-audit-responder \
         s3-tax-reviewer s4-capital-market-disclosure-reviewer s5-fair-trade-reviewer; do
  ln -sfn "$PWD/$p" "$HOME/.claude/skills/$p"
done
ls -l ~/.claude/skills/ | grep -E "orchestrator|s[1-5]-"
```

## 3. 사용자가 직접 수행할 작업

### 3.1 claude.ai 개인 스킬 재등록

압축 파일을 먼저 생성합니다.

```bash
cd ~/My_project/Claude_Project/k-finance-personas
python3 docs/tools/build_packages.py
```

저장소 최상위에 페르소나별 압축 파일 여섯 개가 생성됩니다. claude.ai의 설정에서 개인 스킬로 순차 등록하며, 새 판의 작동을 확인한 뒤 이전 판의 스킬을 삭제합니다.

## 4. 자료 확보 후 착수할 작업

두 건은 산출물 원본이 없어 착수할 수 없습니다. 원본은 claude.ai 세션에만 있으며 로컬 디스크에서는 발견되지 않았습니다.

| 작업 | 필요한 자료 |
|---|---|
| 두 개 산출물에 결정론 항목 소급 적용 | 임차인 인테리어 비용 보전 검토서, 거래 사실관계 통합 검토서 |
| 시험 기록의 잔여 지표 기입 | 위 두 산출물의 참여 분과, 교차 검토 범위, 외부 자료 확인 횟수 |

원본을 확보하면 `docs/02_시험기록.md` 제4절의 「미기록」 항목을 채웁니다.

## 5. 실무 사용 시 확인할 사항

새 판을 적용한 뒤 첫 실무 호출에서 다음을 확인합니다.

1. 페르소나가 사안의 영향도를 스스로 판단하는지 확인합니다.
2. 권장 형식을 제시하고 선택을 요청하는지 확인합니다.
3. 형사 영역 신호가 있는 사안에서 질의 없이 상세형으로 상향하는지 확인합니다.
4. 산출물의 문장이 서술 기준을 지키는지 확인합니다.

확인 결과는 `docs/02_시험기록.md`에 기록합니다.
