# 시험 기록

본 문서는 라이브러리를 실무에 적용한 결과를 누적하는 기록입니다. 안정화 판정은 시험 5건이 누적된 시점에 수행합니다.

## 1. 누적 현황

| 구분 | 건수 |
|---|---|
| 판정 기준 | 5건 |
| 현재 누적 | 3건 |
| 중대 결함 누계 | 0건 |
| 경미 결함 누계 | 12건 |

## 2. 시험 목록

| 식별자 | 사안 | 중대 결함 | 경미 결함 | 결정론 항목 | 비고 |
|---|---|---:|---:|---|---|
| V15-T1 | 토지 현물출자를 통한 신설 리츠 지분 취득 (다섯 개 분과 통합) | 0 | 6 | 적용 | 다섯 개 분과가 모두 본문에 참여한 첫 사례입니다 |
| V15-T2 | 임차인 인테리어 비용 보전 | 0 | 2 | 미적용 | 조건별 분기를 줄글로 서술하여 표로 압축할 여지가 남았습니다 |
| V15-T3 | 거래 사실관계 통합 검토 (차액정산 약정) | 0 | 4 | 미적용 | 교차 검토와 외부 자료 인용은 충실하였으나 형식 판단 절차가 없었습니다 |

## 3. 정량 지표

정량 지표는 별도 파일로 관리합니다. 소재는 `~/Downloads/files/04_agent_time_tracker_v0.3.3.xlsx` 입니다.

| 시트 | 내용 |
|---|---|
| 측정 단위 | 지표 M1부터 M12까지의 정의와 산식 |
| 초기 시험 누적 | 안정화 이전 시험 6건의 기록 |
| 실무 시험 누적 | 본 문서 제2절과 동일한 시험의 정량 지표 |
| 시간 회수 요약 | 수식으로 자동 집계하는 대시보드 |

## 4. 미기입 항목

V15-T2와 V15-T3은 산출물 원본을 확보하지 못하여 환경, 참여 분과, 교차 검토 범위, 외부 자료 확인 횟수, 통합 소요 시간이 기록되지 않았습니다. 추정으로 기입하면 결정론 보증과 고유명사 규칙에 어긋나므로 「미기록」으로 남겨 두었습니다. 원본을 확보하면 기입합니다.

## 5. 기록 규칙

- 실무에 적용할 때마다 제2절에 행을 추가하고 제1절의 누적 건수를 갱신합니다.
- 중대 결함은 발견 즉시 `03_결정기록.md`에 원인과 조치를 기록합니다.
- 확인하지 못한 항목은 「미기록」으로 남기며 추정으로 채우지 않습니다.
- 판정 기준에 도달하면 정량 평가를 수행하고 안정화 여부를 판정합니다.
