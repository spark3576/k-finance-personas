## 2. 구축 완료 항목

- 여섯 개 페르소나의 정의와 행동 규칙을 확정하였습니다.
- 공용 행동 규칙 R1부터 R10까지를 정의하였습니다.
- 공용 오류 유형 AP1부터 AP17까지를 정의하였습니다.
- 산출물 서식과 형식별 구성 요건을 확정하였습니다.
- 결정론 보증 체계를 도입하여 같은 가정에서 같은 결론이 나오도록 하였습니다.
- 정보 밀도 최적화 체계를 도입하여 사안의 영향도에 따라 형식을 선택하도록 하였습니다.
- 문서와 산출물의 서술 기준을 정의하고 자동 점검기를 구축하였습니다.
- 공용 자산 동기화 도구와 배포 압축 파일 생성 도구를 구축하였습니다.
- 공용 자산 3종, 페르소나 6종의 정의 문서와 상세 매뉴얼, 저장소 소개 문서를 서술 기준에 맞추어 전면 개편하였습니다. 문서 43건이 자동 점검을 통과합니다.

## 3. 진행 중인 검토 건

### 3.1 토지 현물출자를 통한 신설 리츠 지분 취득

산출물 네 종이 완성되어 있으며, 소재는 `~/Downloads/files/` 입니다.

확정된 결론은 다음과 같습니다.

- 지분 30%는 회계기준과 상법상 자회사에 해당하지 않으며, 관계기업 또는 단순 투자로 인식합니다.
- 법인세법 제47조의2 적격현물출자의 보유 요건에 미달하여 부적격이 확정되며, 양도차익 전액이 즉시 익금에 산입됩니다.
- 공정거래법 제26조 대규모내부거래 공시가 발동합니다.

미확정 변수 네 가지는 보수적 가정으로 잠겨 있으며, 호출자의 회신을 받으면 판번호를 올려 갱신합니다.

| 변수 | 현재 가정 | 잠긴 결론 |
|---|---|---|
| A 사업보고서 제출대상 여부 | Yes | 자본시장법 제161조 발동, 결의 익일 공시 |
| B 동일인의 자연인 여부 | Yes | 공정거래법 제47조 신호, 외부 법무법인 자문 필요 |
| C 잔여 지분 출자자 구조 | 분산 | 기업결합신고 면제 적용 가능 |
| D 토지 장부가액 | 3,000억 원 | 즉시 법인세 약 1,694억 원 |
