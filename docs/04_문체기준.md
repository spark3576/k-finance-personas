# 서술 기준

본 저장소의 모든 문서와, 본 저장소의 페르소나가 생성하는 모든 산출물에 예외 없이 적용하는 서술 기준입니다. 문서를 새로 쓰거나 고칠 때 이 기준을 먼저 확인합니다.

## 1. 기준의 목적

본 라이브러리의 문서는 작성자 한 사람의 작업 메모가 아니라, 사정을 모르는 제3자가 읽고 이해할 수 있는 자료여야 합니다. 외부 자문 법인, 감사인, 사내 임원, 후임 담당자가 별도 설명 없이 읽을 수 있는 수준을 목표로 합니다.

## 2. 문장 규칙

| 항목 | 기준 |
|---|---|
| 본문 종결 | 「-습니다 / -ㅂ니다」 정중체로 통일합니다 |
| 금지 종결 | 평서형 「-다」체(…했다, …이다, …한다), 명사 나열형 종결(…우선, …금지, …아님) |
| 제목·소제목 | 명사형으로 끝냅니다. 서술형 종결과 물음표를 쓰지 않습니다 |
| 문장 길이 | 90자를 넘으면 두세 문장으로 나눕니다 |
| 화자 노출 | 「…해 보았습니다」, 「…여쭙습니다」처럼 화자가 과도하게 드러나는 표현을 절제합니다 |
| 구어체 | 쓰지 않습니다. 원문 인용은 예외로 합니다 |

## 3. 용어 규칙

영문 업무 용어를 한국어 문장에 그대로 섞지 않습니다. 아래 대응표를 적용하며, 실무에서 원어가 정착된 용어만 최초 1회 괄호로 병기합니다.

| 쓰지 않는 표현 | 사용하는 표현 |
|---|---|
| universal, universal 자산 | 공용 자산 |
| mandatory | 필수 |
| substrate | 축적 사례, 근거 사례 |
| hotfix | 긴급 개정 |
| cross-reference, cross-ref | 교차 검토 |
| Bottom Line | 핵심 요약 |
| 3-tier | 3단계 |
| prose | 줄글 |
| if-then | 조건별 분기 |
| retrofit | 소급 적용 |
| 디폴트 | 기본값 |
| 룰, 뎁스, 시그널, 체크 | 규칙, 단계, 신호, 확인 |
| 매트릭스 | 대조표 |
| 격상, 격하 | 상향, 하향 |
| critical / major / minor | 중대 / 주요 / 경미 |
| ROI | 투자 대비 효과 |
| Inverted Pyramid | 두괄식 |
| DCF | 현금흐름할인법 |
| IRR | 내부수익률 |
| NPV | 순현재가치 |
| WACC | 가중평균자본비용 |
| EBITDA | 이자·법인세·감가상각비 차감 전 영업이익 |
| LTV | 담보인정비율 |
| DSCR | 부채상환계수 |
| cap rate | 자본환원율 |
| covenant | 재무약정 |
| due diligence | 실사 |
| FP&A | 재무 계획과 분석 |
| 리파이낸싱 | 차환 |

## 4. 표기 규칙

- 강조는 굵은 글씨를 사용하며, 문장 중간에 별표를 넣는 방식은 쓰지 않습니다.
- 인용과 지칭에는 낫표(「 」)를 사용합니다.
- 판정 표기에는 기호 대신 「적절한 예」, 「부적절한 예」라고 씁니다.
- 규칙 식별자(R1~R10, AP1~AP21)는 시스템 전반에서 참조하므로 유지하되, 처음 등장할 때 규칙 이름을 함께 적습니다.
- 실재하는 회사명과 인명은 예시에 쓰지 않습니다. 「甲사」, 「A사」 같은 가칭을 사용합니다.

## 5. 구성 규칙

- 문서에는 내용만 담습니다. 개정 이력, 작업 경위, 적용 사양 설명은 별도 문서로 분리합니다.
- 내부 작업 용어와 내부 식별번호는 문서 본문에 노출하지 않습니다. 시험 식별자는 시험 기록 문서에만 둡니다.
- 같은 내용을 두 곳에 중복 기재하지 않습니다.
- 조건별 분기, 정량 비교, 항목 대조는 줄글이 아니라 표로 제시합니다.

## 6. 자가 점검 항목

문서를 저장하기 전 아래를 확인합니다.

1. 평서형 「-다」체 종결이 남아 있지 않은지 확인합니다.
2. 제3절 대응표의 좌측 표현이 남아 있지 않은지 확인합니다.
3. 제목이 명사형으로 끝나는지 확인합니다.
4. 개정 이력과 작업 경위가 본문에 섞여 있지 않은지 확인합니다.
5. 사정을 모르는 사람이 읽었을 때 뜻이 통하는지 소리 내어 확인합니다.

점검은 `docs/tools/check_style.py`로 기계 검사할 수 있습니다.
