# 개정 이력

본 문서는 판번호별 변경 내역을 기록합니다. 규칙과 서식을 정의한 본문 문서에서 분리하여 이곳에 모았습니다.

## V1.8 — 2026-09-08

**서술 기준 정비와 운영 구조 신설.** 기능 변경은 포함하지 않습니다.

- 문서와 산출물의 서술 기준을 `docs/04_문체기준.md`로 정의하고 자동 점검기 `docs/tools/check_style.py`를 구축하였습니다.
- 공용 자산 3종과 페르소나 6종의 `SKILL.md`, `README.md`를 서술 기준에 맞추어 전면 개편하였습니다. 영문 업무 용어를 한국어로 옮기고, 평서형 종결을 정중체로 통일하였으며, 문장 중간의 별표 강조와 판정 기호를 제거하였습니다.
- 산출물 서식 항목의 이름을 한국어로 통일하였습니다. 머리글, 바닥글, 제3자 관점 검증, 약점과 불확실성, 외부 자료 확인, 자기 평가, 핵심 요약이 그것입니다.
- 각 문서에 섞여 있던 개정 이력과 작업 경위를 본 문서로 분리하였습니다.
- 중복 기재되어 있던 개정 이력 블록을 제거하였습니다. 공용 규칙과 오류 유형 문서에 같은 내용이 두 번씩 들어 있었습니다.
- 여러 세션에 걸친 작업을 위한 운영 문서 체계를 신설하였습니다. 현황판, 설계도, 시험 기록, 결정 기록, 서술 기준, 후속 작업, 개정 이력의 일곱 개 문서입니다.
- 공용 자산 동기화 도구 `docs/tools/sync_shared.py`와 배포 압축 파일 생성 도구 `docs/tools/build_packages.py`를 구축하였습니다.
- Claude Code 세션 진입 지침 `CLAUDE.md`와 고정 파일명 인계서 `HANDOFF.md`를 신설하였습니다.
- 오류 유형의 식별자는 재번호하지 않고 유지하였습니다. 과거 산출물과 시험 기록이 기존 식별자를 참조하기 때문입니다.
